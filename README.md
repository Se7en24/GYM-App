# 🏋️‍♂️ GYM-App (Gym Membership Management System)

A lightweight **C# + SQL** based Gym Membership Management System designed for **admin/owner use only**.  
This system allows the gym owner to manage members, track expiry dates, handle fines, and renew or remove memberships easily.

---

## ✅ Key Features

### 🔹 Member Management
- Add new gym members with full details  
- View all active members  
- Delete/remove members permanently  

### 🔹 Membership Tracking
- Track membership start & end dates  
- Identify expired or near-expiry memberships  
- Renew memberships with updated plans and dates  

### 🔹 Fine Handling
- Add or update fines for late payments  
- Keep a record of members with pending dues  

### 🔹 Admin-Only System
- No member login — only the owner/admin manages everything  
- Simple interface focused on speed and practicality  

---

### **Language:**

- **SQL Database (Offline Local DB)**
